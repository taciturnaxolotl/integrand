integrand options

Service endpoint

Point this at your own box to stop using someone else's compute. The manifest grants access to localhost only, so a remote endpoint needs a matching host_permissions entry.

Sites with the button

On these sites a small ∫ sits on the right edge — but only on pages where it actually finds maths, so a login page stays clean. Everywhere else, snipping still works from the toolbar button, the right-click menu, or ⌘⇧Y.
